# Add-ons Home Assistant

Dépôt d'add-ons personnels, à ajouter dans Home Assistant par
**Paramètres → Modules complémentaires → Boutique → ⋮ → Dépôts**.

| Add-on | Rôle |
|---|---|
| [Collecte Sèvre Nantaise](collecte-sevre/) | Archive la lame d'eau radar toutes les 5 minutes et recalcule la prévision de crue de Rochereau |

Ce dépôt ne contient **aucune donnée et aucun secret** : seulement la recette de
construction. Les données vivent sur la Pi, la clé Météo-France se saisit dans la
configuration de l'add-on.
